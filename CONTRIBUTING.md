# Contributing

Thanks for helping improve Builder's Dashboard. Small, focused contributions are especially useful while the project is early.

## Before opening an issue

- Search existing issues for duplicates.
- Describe the workflow or problem, not only a proposed solution.
- Include your operating system, Python version, browser, steps to reproduce, and expected versus actual behavior.
- Remove credentials, tokens, private project details, and personal data from logs and screenshots.

## Pull requests

1. Keep changes focused and explain the user problem they solve.
2. Avoid adding dependencies unless there is a clear reason.
3. Test the dashboard in a browser and, for API changes, test valid and invalid requests.
4. Update the README when setup, behavior, or limitations change.
5. State what you tested and what you could not test.

## Product direction

This project is exploring a simple local-first dashboard for builders who use AI coding agents. Feedback about actual workflows and repeat usage is more valuable than speculative feature lists. Please explain what you currently use, what is missing, and why the missing piece matters.
